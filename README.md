# NAITE 채널 운영 대시보드

9개 채널(강사·전문 6 · 재테크 2 · 도서리뷰 1, 브랜딩 준비중 1) 운영 현황을 한눈에 보는
정적 대시보드입니다. Google 스프레드시트에 숫자만 입력하면 자동으로 반영됩니다.

## 1. Google 스프레드시트 만들기

새 스프레드시트를 만들고 아래 3개 탭을 정확히 이 이름으로 생성하세요.
`templates/` 폴더의 CSV 파일을 그대로 각 탭에 가져오기(파일 > 가져오기 > 업로드 >
"현재 시트를 바꿉니다") 하면 헤더와 예시 행이 세팅됩니다.

| 탭 이름 | 파일 | 용도 |
|---|---|---|
| `일별데이터` | `templates/일별데이터_template.csv` | 매일/매주 실제로 입력하는 곳 |
| `주간루틴` | `templates/주간루틴_template.csv` | 요일별 발행 완료 체크 (TRUE/FALSE) |
| `채널마스터` | `templates/채널마스터_template.csv` | 채널·그룹 정보 (거의 고정) |

**채널마스터 - 예약발행마감일 (예약 소진 추적)**
- 예약 포스팅을 큐에 올릴 때마다 해당 채널 행의 `예약발행마감일`을 "예약이 소진되는 날짜"로 갱신하세요
- 대시보드가 오늘 날짜 기준 남은 일수(D-day)를 자동 계산해 **남은 일수 적은 순**으로 최상단에 노출합니다
- 남은 일수 3일 이하 / 마감일 미설정 / 이미 경과 → 빨간 경고 배지, 4~7일 → 주의(노랑), 8일 이상 → 안전(초록)
- 운영중(`상태` = `운영중`)인 채널만 집계 대상입니다 (미시작 채널 제외)

**일별데이터 입력 규칙**
- 한 행 = 하루 한 채널 (여러 채널을 올린 날은 여러 행으로 나눠 입력)
- `애드센스수익`은 **채널④(티스토리)**만 입력, 나머지는 공란
- `애드센스승인상태`는 **채널③(티스토리)**만 입력. 값은 `승인대기` / `심사중` / `반려` / `승인완료` 중 하나
- 채널명은 `채널마스터` 탭의 `채널명`과 **정확히 동일한 문자열**이어야 합니다 (예: `티스토리④`)

**주간루틴 입력 규칙**
- 월=채널④, 화=채널③, 수=채널②, 목=채널④, 금=채널① 발행 완료 여부를 체크박스로 표시
- 시트에서 해당 셀을 체크박스 데이터 검증으로 설정해두면 편합니다 (삽입 > 체크박스)

## 2. 스프레드시트 공유 설정

우측 상단 **공유** 버튼 > **일반 액세스**를 **"링크가 있는 모든 사용자" (뷰어)**로 설정하세요.
("웹에 게시"는 필요 없습니다 — CSV 방식은 브라우저 CORS 정책에 막히는 경우가 많아 이 대시보드는
Google Visualization API를 사용합니다. 링크 공유 권한만 있으면 됩니다.)

## 3. 대시보드에 연결

1. 스프레드시트 URL에서 `/d/`와 `/edit` 사이의 긴 문자열(스프레드시트 ID)을 복사
2. 각 탭을 클릭할 때 주소창에 뜨는 `#gid=숫자`를 확인 (탭마다 다름, `일별데이터` 탭은 보통 `gid=0`)
3. [assets/config.js](assets/config.js)에 입력:

```js
const SHEET_ID = "스프레드시트ID";
const SHEET_GIDS = {
  daily: 0,          // 탭: 일별데이터
  routine: 123456,   // 탭: 주간루틴
  master: 789012,    // 탭: 채널마스터
};
```

`SHEET_ID`를 비워두면 `assets/sample-data.js`의 샘플 데이터로 미리보기가 동작합니다.

## 4. 로컬 미리보기

브라우저는 보안상 `file://`로 열면 CSV/스크립트 로드가 막힐 수 있습니다. 로컬 서버로 여세요.

```powershell
powershell -ExecutionPolicy Bypass -File preview-server.ps1
```

이후 `http://127.0.0.1:8791` 접속. (Python이 있다면 `python -m http.server 8791`도 가능)

## 5. GitHub Pages 배포

1. 이 폴더를 GitHub 저장소에 푸시
2. 저장소 Settings > Pages > Branch를 `main` (또는 배포 브랜치)로 설정
3. `https://<사용자명>.github.io/<저장소명>/` 로 접속

## 대시보드 구성

- **주간 발행 루틴**: 월~금 담당 채널의 발행 완료 여부 체크
- **애드센스 승인 현황**: 채널③(티스토리) 승인 상태를 배지로 강조 (단기 목표)
- **그룹별 요약**: 강사·전문 / 재테크 / 도서리뷰 최근 7일 게시글수·조회수·수익 + 브랜딩(채널⑥) 준비 상태
- **채널별 추이**: 그룹 선택 + 주간/월간 토글 라인 차트
- **원본 데이터**: 표로 펼쳐보기 (최근 200행)

모든 화면은 모바일 폭(360px~)부터 데스크톱까지 반응형입니다. 우측 상단 🌓 버튼으로
라이트/다크 테마를 전환할 수 있습니다.
